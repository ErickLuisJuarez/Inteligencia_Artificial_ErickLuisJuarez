1. FUNDAMENTOS MATEMÁTICOS

La distancia de Levenshtein entre dos cadenas a y b se define como el número
mínimo de operaciones de edición (inserciones, eliminaciones o sustituciones de
un solo carácter) necesarias para transformar una cadena en otra.

Sea Σ un alfabeto finito. Dadas dos cadenas A = a₁, a₂, ..., aₙ y B = b₁, b₂, ..., bₘ
sobre Σ donde |A| = n y |B| = m.

La función se calcula recursivamente como:

         ⎧ max(i, j)                                  si min(i, j) = 0
lev(i,j) = ⎨
         ⎩ min( lev(i-1, j) + 1,                     // eliminación
                lev(i, j-1) + 1,                     // inserción
                lev(i-1, j-1) + costo )              // sustitución

con:
  costo = 0  si  a[i] = b[j]
  costo = 1  si  a[i] ≠ b[j]

2. ALGORITMO FORMAL (WAGNER-FISCHER)

Entrada: Dos cadenas A y B de longitudes n y m.
Salida: Distancia de Levenshtein L(A, B).

1. Inicializar matriz M de dimensiones (n+1) × (m+1).
2. Para i desde 0 hasta n: M[i][0] ← i
3. Para j desde 0 hasta m: M[0][j] ← j
4. Para i desde 1 hasta n:
     Para j desde 1 hasta m:
       Si A[i] = B[j] entonces costo ← 0
       Si A[i] ≠ B[j] entonces costo ← 1
       M[i][j] ← min( M[i-1][j] + 1, M[i][j-1] + 1, M[i-1][j-1] + costo )
5. Retornar M[n][m]

3. DESCRIPCIÓN FORMAL / NARRATIVA

La distancia de Levenshtein mide cuántas operaciones mínimas de edición
(inserción, eliminación o sustitución de un carácter) se necesitan para
transformar una cadena en otra. Es fundamental para corrección ortográfica,
búsqueda difusa (fuzzy matching) y detección de errores OCR.

La solución óptima se obtiene mediante Programación Dinámica, construyendo
una matriz M de dimensiones (|a|+1) × (|b|+1). Cada celda M[i][j] almacena
el costo mínimo de transformar los primeros i caracteres de a en los primeros
j caracteres de b.

Casos base:
  - M[i][0] = i → transformar i caracteres a cadena vacía = i eliminaciones
  - M[0][j] = j → transformar cadena vacía a j caracteres = j inserciones

4. MÉTRICAS DE COMPLEJIDAD

Complejidad temporal: O(n × m), donde n = |a|, m = |b|.
Complejidad espacial: O(n × m) para almacenar la matriz completa.
Es posible optimizar el espacio a O(min(n, m)) usando solo dos filas.

5. PSEUDOCÓDIGO

FUNCIÓN levenshtein(a, b):
  n ← longitud(a)
  m ← longitud(b)

  CREAR matriz M[0..n][0..m] inicializada en 0

  PARA i DESDE 0 HASTA n:
      M[i][0] ← i
  PARA j DESDE 0 HASTA m:
      M[0][j] ← j

  PARA i DESDE 1 HASTA n:
      PARA j DESDE 1 HASTA m:
          SI a[i-1] = b[j-1]:
              costo ← 0
          SINO:
              costo ← 1

          M[i][j] ← MIN( M[i-1][j] + 1,    // eliminación
                         M[i][j-1] + 1,    // inserción
                         M[i-1][j-1] + costo ) // sustitución

  RETORNAR M[n][m]

// Ejemplo de uso:
distancia ← levenshtein("Gool", "Gol")   // Resultado esperado: 1
