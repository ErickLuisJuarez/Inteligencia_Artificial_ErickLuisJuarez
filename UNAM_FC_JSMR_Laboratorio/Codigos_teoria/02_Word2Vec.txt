1. FUNDAMENTOS MATEMÁTICOS

Word2Vec (Skip-Gram) es una red neuronal de una capa oculta que aprende
representaciones vectoriales densas de palabras (embeddings) basándose en la
hipótesis distribucional: "Palabras que aparecen en contextos similares tienden
a tener significados similares".

Parámetros:
  V = tamaño del vocabulario
  N = dimensión del embedding (espacio latente, típicamente 100-300)

Matrices de pesos:
  W₁ ∈ ℝ^(V×N)   → pesos de entrada (embeddings de palabras)
  W₂ ∈ ℝ^(N×V)   → pesos de salida

Función de Objetivo (Log-Verosimilitud):
Dada una secuencia de palabras de entrenamiento w₁, w₂, ..., w_T, maximizar el
promedio de la log-probabilidad del contexto:

  J(θ) = (1/T) ∑_{t=1}^{T} ∑_{-c ≤ j ≤ c, j ≠ 0} log p(w_{t+j} | w_t)

donde c es el tamaño de la ventana de contexto.

La probabilidad p(w_0 | w_1) se define usando la exponencial del producto punto:

  p(w_0 | w_1) = exp(v_{w_0}^T v_{w_1}) / ∑_{w=1}^{V} exp(v_w^T v_{w_1})

donde v_w y v_w^T son las representaciones de entrada y salida de la palabra w.

Softmax numéricamente estable:
  softmax(x)_i = exp(x_i - max(x)) / ∑_j exp(x_j - max(x))

Función de pérdida (entropía cruzada):
  L = -log(ŷ_c) donde c es el índice de la palabra contexto real

2. ALGORITMO FORMAL (SKIP-GRAM CON SOFTMAX)

Entrada: Corpus de texto, dimensión N, tamaño de ventana c, tasa de aprendizaje lr.
Salida: Matriz de embeddings W₁ (V × N).

1. Inicializar W₁ y W₂ con valores aleatorios pequeños.
2. Para cada época:
     Para cada palabra central w_t en el corpus:
       Obtener palabras contexto w_{t+j} dentro de ventana de tamaño c.
       Para cada palabra contexto:
         h ← W₁[índice_central]          // capa oculta (vector de N dimensiones)
         u ← h · W₂                       // logits (vector de V dimensiones)
         ŷ ← softmax(u)                   // probabilidades de salida
         e ← ŷ - one_hot(contexto)        // error
         // Retropropagación
         W₂ ← W₂ - lr · (h ⊗ e)           // actualizar pesos de salida
         W₁[índice_central] ← W₁[índice_central] - lr · (W₂ · e)
3. Retornar W₁

3. DESCRIPCIÓN FORMAL / NARRATIVA

Word2Vec aprende a representar palabras como vectores numéricos en un espacio
de N dimensiones, de modo que palabras con significado similar queden
geométricamente cercanas. El modelo Skip-Gram toma una palabra de entrada
y trata de predecir las palabras de su contexto.

Mientras que la distancia de Levenshtein mide similitud ortográfica,
Word2Vec captura similitud semántica. Por ejemplo, "delantero" y "atacante"
tendrán vectores cercanos porque aparecen en contextos similares, mientras que
"Messi" y "Massa" serán distantes a pesar de su similitud ortográfica.

Tras el entrenamiento, la matriz W₁ contiene los embeddings entrenados de
cada palabra del vocabulario.

4. MÉTRICAS DE COMPLEJIDAD

Complejidad temporal (entrenamiento): O(E × T × c × log V)
  donde E = número de épocas, T = número de palabras en el corpus,
  c = tamaño de ventana, V = tamaño del vocabulario.
  (El uso de Hierarchical Softmax o Negative Sampling reduce el costo de V a log V)

Complejidad espacial: O(V × N)
  donde V = vocabulario, N = dimensión del embedding.
  Se necesitan almacenar dos matrices: W₁ (entrada) y W₂ (salida).

5. PSEUDOCÓDIGO

FUNCIÓN inicializar(V, N):
  W₁ ← matriz aleatoria de shape (V × N)
  W₂ ← matriz aleatoria de shape (N × V)
  RETORNAR W₁, W₂

FUNCIÓN softmax(x):
  e_x ← exp(x - max(x))           // estabilidad numérica
  RETORNAR e_x / suma(e_x)

FUNCIÓN entrenar(x_entrada, c_contexto, W₁, W₂, lr=0.01):
  // Forward pass
  h ← W₁[x_entrada]                // capa oculta
  u ← h · W₂                       // logits
  y_pred ← softmax(u)              // probabilidades

  // Construir vector one-hot del contexto real
  y_true ← vector de ceros de tamaño V
  y_true[c_contexto] ← 1

  // Calcular error y actualizar pesos
  e ← y_pred - y_true
  dW₂ ← producto_externo(h, e)     // gradiente para W₂
  dW₁ ← W₂ · e                     // gradiente para W₁[x]
  W₂ ← W₂ - lr * dW₂
  W₁[x_entrada] ← W₁[x_entrada] - lr * dW₁

// Ejemplo de uso:
W₁, W₂ ← inicializar(V=3, N=2)    // vocabulario: {'gol':0, 'messi':1, 'futbol':2}
entrenar(x_entrada=1, c_contexto=0, W₁, W₂)   // "messi" → predice "gol"
