1. FUNDAMENTOS MATEMÁTICOS

SIFT detecta y describe puntos clave invariantes a escala, rotación e
iluminación. Identifica características locales dentro de una imagen conocidas
como puntos de interés que no se ven afectadas por el tamaño de la imagen o su
orientación.

ETAPA 1 – Espacio de escala (DoG, Difference of Gaussians):
  L(x, y, σ) = G(x, y, σ) * I(x, y)
  D(x, y, σ) = L(x, y, kσ) - L(x, y, σ)

  donde G es un kernel gaussiano de desviación σ,
  * denota convolución, y k es un factor de escala constante.
  DoG aproxima el Laplaciano de Gaussiano (LoG) para detectar puntos de interés
  en diferentes escalas.

ETAPA 2 – Detección de extremos locales:
  Un píxel es punto clave candidato si es máximo o mínimo local comparado con
  sus 26 vecinos en espacio y escala (3 capas DoG): los 8 vecinos en la misma
  escala, más 9 de la escala superior y 9 de la escala inferior.

ETAPA 3 – Asignación de orientación:
  Para cada punto clave, se calcula el histograma de gradientes en una vecindad
  16×16 alrededor del punto. El histograma tiene 36 barras (10° cada una)
  cubriendo 360°.

  Magnitud:    m(x,y) = √( (L(x+1,y)-L(x-1,y))² + (L(x,y+1)-L(x,y-1))² )
  Orientación: θ(x,y) = arctan( (L(x,y+1)-L(x,y-1)) / (L(x+1,y)-L(x-1,y)) )

ETAPA 4 – Descriptor de 128 dimensiones:
  La vecindad 16×16 se divide en 16 sub-regiones de 4×4.
  Cada sub-región genera un histograma de 8 orientaciones.
  Total: 16 × 8 = 128 valores → vector descriptor normalizado (norma L2).

2. ALGORITMO FORMAL

Entrada: Imagen I en escala de grises.
Salida: Conjunto de puntos clave K y descriptores D (matriz N×128).

1. Construir pirámide gaussiana: L[o][s] = G(σ[o][s]) * I para cada octava o y escala s.
2. Calcular Difference of Gaussians: D[o][s] = L[o][s+1] - L[o][s].
3. Detectar extremos locales en D[o][s] comparando cada píxel con sus 26 vecinos.
4. Refinar puntos clave usando expansión en series de Taylor del espacio de escalas.
5. Filtrar puntos con bajo contraste (intensidad < umbral 0.03) y puntos sobre bordes.
6. Para cada punto clave:
     a. Calcular magnitud y orientación en vecindad.
     b. Construir histograma de orientaciones (36 bins).
     c. Asignar orientación(es) dominante(s).
7. Para cada punto clave:
     a. Extraer región 16×16 rotada según orientación dominante.
     b. Dividir en 16 subregiones de 4×4.
     c. Calcular histograma de 8 orientaciones por subregión.
     d. Concatenar en vector de 128 dimensiones y normalizar.
8. Retornar puntos clave y descriptores.

3. DESCRIPCIÓN FORMAL / NARRATIVA

SIFT identifica puntos clave robustos en una imagen (esquinas, manchas, etc.)
y genera para cada uno una "huella digital" vectorial de 128 dimensiones que
no cambia aunque la imagen sea rotada, escalada o tenga diferente iluminación.

Pasos del proceso:
  1. Construir pirámide gaussiana: aplicar sucesivamente filtros gaussianos
     de distinta sigma a la imagen en diferentes octavas.
  2. Calcular diferencias entre capas consecutivas (DoG) para detectar
     estructuras estables a distintas escalas.
  3. Buscar extremos locales (máximos y mínimos) en los mapas DoG comparando
     cada píxel con sus 26 vecinos 3D.
  4. Refinar y filtrar puntos candidatos (eliminar puntos con bajo contraste
     o sobre bordes usando la matriz Hessiana).
  5. Asignar una orientación dominante a cada punto clave mediante histograma
     de gradientes (36 bins, 10° cada uno).
  6. Calcular el descriptor de 128 valores y normalizarlo.

El resultado es una lista de puntos clave (coordenada + escala + orientación)
y sus descriptores (matriz N×128), que pueden usarse para comparar o emparejar
imágenes, incluso bajo diferentes perspectivas y escalas.

4. MÉTRICAS DE COMPLEJIDAD

Complejidad temporal: O(N), donde N es el número de píxeles, pero con una
  constante muy alta debido a la construcción de la pirámide Gaussiana
  (típicamente 4 octavas con 5 escalas cada una) y el cálculo de los 128
  descriptores por punto clave. Es computacionalmente costoso en comparación
  con operadores locales como Sobel.

Complejidad espacial: O(N × S), donde S es el número de escalas (típicamente
  20-30 imágenes en toda la pirámide), debido al almacenamiento de la pirámide
  de imágenes y los mapas DoG.

5. PSEUDOCÓDIGO

FUNCIÓN extraer_caracteristicas_sift(imagen_uint8):
  // Validaciones
  SI imagen no es np.ndarray:
      LANZAR error "Se requiere np.ndarray"
  SI imagen no es 2D:
      LANZAR error "Se requiere imagen en escala de grises"
  SI dtype de imagen no es uint8:
      LANZAR error "Se requiere dtype uint8; usar img_as_ubyte()"

  // ── ETAPA 1: Espacio de escala ──────────────────────────────
  PARA cada octava o:
      PARA cada nivel de escala s:
          L[o][s] ← convolución_gaussiana(imagen, sigma[o][s])
          D[o][s] ← L[o][s+1] - L[o][s]     // Difference of Gaussians

  // ── ETAPA 2: Detección de extremos locales ──────────────────
  candidatos ← []
  PARA cada D[o][s] (excluyendo primera y última capa):
      PARA cada píxel (x, y):
          vecinos_26 ← píxeles en (x±1, y±1, s±1)
          SI D[o][s][x,y] es máximo O mínimo de vecinos_26:
              candidatos.agregar( (x, y, o, s) )

  // ── ETAPA 3: Refinamiento y filtrado ────────────────────────
  puntos_clave ← []
  PARA cada (x, y, o, s) EN candidatos:
      SI contraste < umbral (0.03):
          CONTINUAR                  // descartar bajo contraste
      SI punto sobre borde (ratio de curvaturas > umbral):
          CONTINUAR                  // descartar bordes
      puntos_clave.agregar( (x, y, o, s) )

  // ── ETAPA 4: Asignación de orientación ──────────────────────
  PARA cada punto_clave EN puntos_clave:
      histograma_36 ← calcular_histograma_gradientes(vecindad_16x16)
      orientacion_dominante ← argmax(histograma_36) * 10°
      punto_clave.orientacion ← orientacion_dominante

  // ── ETAPA 5: Cálculo del descriptor 128-D ───────────────────
  descriptores ← []
  PARA cada punto_clave EN puntos_clave:
      descriptor ← vector vacío de 128 valores
      region_16x16 ← extraer_region_rotada(imagen, punto_clave)
      PARA cada subregion_4x4 (16 en total):
          hist_8 ← histograma_de_gradientes(subregion_4x4, bins=8)
          descriptor.concatenar(hist_8)
      descriptor ← normalizar_L2(descriptor)
      descriptores.agregar(descriptor)

  // Resultado final
  RETORNAR puntos_clave, descriptores     // descriptores shape (N, 128)

// Ejemplo de uso:
imagen_float ← convertir_a_gris(imagen_rgb)
imagen_uint8 ← img_as_ubyte(imagen_float)
kp, des ← extraer_caracteristicas_sift(imagen_uint8)
IMPRIMIR "Puntos clave:", longitud(kp)
IMPRIMIR "Shape descriptores:", forma(des)   // (N, 128)
