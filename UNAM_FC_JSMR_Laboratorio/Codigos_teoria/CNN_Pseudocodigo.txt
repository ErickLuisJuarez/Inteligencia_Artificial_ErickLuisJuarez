PSEUDOCÓDIGO — Red Neuronal Convolucional (CNN) Didáctica

═══════════════════════════════════════
 CLASE: CapaConvolución
═══════════════════════════════════════

INICIALIZAR(num_filtros, tamaño_kernel):
    filtros ← valores aleatorios normalizados
               de forma (num_filtros, tamaño_kernel, tamaño_kernel)
               divididos entre (tamaño_kernel²) para estabilizar

OBTENER_REGIONES(imagen):
    h, w ← dimensiones de la imagen
    Para i desde 0 hasta (h - tamaño_kernel):
        Para j desde 0 hasta (w - tamaño_kernel):
            region ← imagen[i : i+tamaño_kernel, j : j+tamaño_kernel]
            Ceder (region, i, j)

FORWARD(entrada):
    Guardar entrada como última_entrada
    h, w ← dimensiones de entrada
    salida ← zeros(h - tamaño_kernel + 1,
                   w - tamaño_kernel + 1,
                   num_filtros)

    Para cada (region, i, j) en OBTENER_REGIONES(entrada):
        salida[i, j] ← suma del producto_punto(region, filtros)
                        a lo largo de los ejes 1 y 2
    Retornar salida

BACKWARD(d_L_d_salida, learning_rate):
    d_L_d_filtros ← zeros(forma de filtros)

    Para cada (region, i, j) en OBTENER_REGIONES(última_entrada):
        Para cada filtro f:
            d_L_d_filtros[f] += region × d_L_d_salida[i, j, f]

    # Actualizar filtros — Descenso de Gradiente
    filtros -= learning_rate × d_L_d_filtros

    # Nota: propagación del error hacia atrás omitida (capa simple)
    Retornar None

 CLASE: CapaMaxPooling (tamaño_pool=2)
═══════════════════════════════════════

INICIALIZAR(tamaño_pool):
    tamaño_pool ← tamaño_pool

OBTENER_REGIONES(imagen):
    h, w, num_filtros ← dimensiones de la imagen
    nuevo_h ← h // tamaño_pool
    nuevo_w ← w // tamaño_pool

    Para i desde 0 hasta nuevo_h:
        Para j desde 0 hasta nuevo_w:
            region ← imagen[i×pool : (i+1)×pool,
                            j×pool : (j+1)×pool]
            Ceder (region, i, j)

FORWARD(entrada):
    ...  [reducir tomando el MÁXIMO de cada región pool×pool]

BACKWARD(...):
    ...  [propagar gradiente solo a la posición del máximo]

COMPLEJIDAD EN TIEMPO:
  - Entrenamiento: O(capas · filtros · tamaño_imagen · kernel²)
      (intensivo en cómputo → se usan GPUs)
 
COMPLEJIDAD EN ESPACIO:
  - O(parámetros)
      (eficientes por weight sharing: los filtros se comparten en toda la imagen)

DEFINICIÓN (Red Neuronal Artificial):
Modelo de IA inspirado en cómo funciona el cerebro humano. Aprende
a partir de ejemplos para tomar decisiones o hacer predicciones.
Está formada por neuronas artificiales conectadas que procesan
información numérica.

FUNDAMENTOS MATEEMATICOS

Operación de Convolución:
  (X * K)ᵢ,ⱼ = ΣΣ  X_{i+p, j+q} · K_{p,q}
 
  Donde K = filtro/kernel de tamaño m×n.
 
Función de Activación ReLU:
  f(x) = max(0, x)
 
Pooling:
  Se toma el máximo o promedio en una vecindad de k×k para reducir dimensionalidad.
